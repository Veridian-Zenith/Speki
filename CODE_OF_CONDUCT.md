# Code of Conduct

## Expectation

Be precise, be kind, review the code not the person. Numerical code fails in
subtle ways; review rigor is care, not hostility.

## Unacceptable

Harassment, discrimination, intimidation, dismissive review, sleeping on
security reports.

## Mods and admins

Every item in this document applies to moderators and administrators verbatim.
No rank exempts anyone.

Abuse of power - using admin or moderation privileges to harass, silence,
exile, or retaliate against someone, or to shield anyone else from the rules
here - results in a permanent ban from contributing to the project as a whole.
Not a warning, not a suspension: a full ban, with no route to appeal inside the
project.

The same reporting route as anyone else, and it is handled the same way:
[SECURITY.md](SECURITY.md) or
[daedaevibin@ik.me](mailto:daedaevibin@ik.me).

This is stated plainly because it is the case a code of conduct usually does
not cover, and where a single point of failure otherwise goes unchecked.

## Enforcement

Report via the private security channel ([SECURITY.md](SECURITY.md)) or
maintainer email [daedaevibin@ik.me](mailto:daedaevibin@ik.me). Maintainer
investigates, may warn, temporarily or permanently ban from contribution, and
will not retaliate against reporters.

## Scope

Applies in the repo, issues, PRs, and when representing speki elsewhere.
